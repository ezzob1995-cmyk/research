# 🔬 מערכת מחקר מחלקתי — גרסה 2

מערכת אינטרנטית לאיסוף נתוני מחקר ע"י צוות המחלקה: בדיקות דם עם חישוב **גיל ביולוגי (PhenoAge, נוסחת לווין)**, הערכות רגליים והזנחה, שינויי תרופות, וכל טופס נוסף שהמנהל יוצר — עם הרשאות, הערות לרופא/ה, מעקב ביקורים, אישור נתונים, ניתוח ותרשימים וייצוא לאקסל.

## מה יש במערכת

| תחום | מה |
|---|---|
| **טפסים ובדיקות** | המנהל מוסיף בדיקות, שדות וטפסים שלמים ממסך "טפסים ובדיקות" — בלי קוד. סוגי שדות: מספר (עם יחידות וטווח סביר), טקסט, תאריך, רשימה, בחירה אחת/מרובה, כן/לא, בחירה עם ניקוד. חישובים: PhenoAge, BMI, סכום ניקוד עם רמות. שדה עם נתונים לא נמחק — "מוסר" והנתונים נשמרים. |
| **הרשאות** | 3 תפקידים: צוות, רופא/ה, מנהל. לכל איש צוות ולכל טופס: הזנה / עריכת שלו / עריכת כולם / מחיקת שלו / מחיקת כולם. בנוסף: גיוס מטופלים, אישור ונעילה, צפייה בסטטיסטיקה, ייצוא. |
| **רופא/ה** | הערות ושאלות על מטופל או על הזנה, שרשור תגובות, סימון "טופל". **התראות אוטומטיות** לרופא/ה על ערכים חריגים (מוגדרות בכל טופס). |
| **מחקר** | קריטריוני הכללה/אי-הכללה, תאריך הסכמה, פרישה וסיבתה · מעקב ביקורים לפי תדירות לכל טופס · טופס "שינוי תרופתי" · אישור ונעילת הזנות · מסך איכות נתונים · תרשימים: ביולוגי מול כרונולוגי, פער לפי קבוצת תרופות/אבחנה/מחלקה, שינוי לאורך זמן. |
| **ייצוא** | אקסל: מטופלים, גיליון לכל טופס (כל ביקור שורה), הערות, ביצועי צוות, מילון משתנים. מצב SPSS (שמות באנגלית, ניקוד כמספרים). |

## שדרוג מגרסה 1 (המערכת כבר מותקנת)
1. Supabase → **SQL Editor** → New query → להדביק את כל `sql/upgrade_v2.sql` → **Run**. (לא מוחק שום נתון.)
2. GitHub → המאגר → **Add file → Upload files** → לגרור את כל הקבצים מהחבילה (חוץ מ-`js/config.js`, שלא נמצא בחבילה כדי לא לדרוס את ההגדרות) → **Commit**.
3. אחרי 2–3 דקות: לפתוח את האתר ולהתחבר מחדש.
(הקובץ הישן `js/forms.js` כבר לא בשימוש — אפשר למחוק אותו מהמאגר.)

## התקנה חדשה
1. Supabase → New project (Region: אירופה) → SQL Editor → להריץ `sql/schema.sql` ואחריו `sql/upgrade_v2.sql`.
2. ליצור `js/config.js`:
```js
window.APP_CONFIG = {
  SUPABASE_URL: 'https://xxxx.supabase.co',
  SUPABASE_KEY: 'sb_publishable_...',   // לעולם לא secret / service_role
  IDLE_LOGOUT_MINUTES: 20
};
```
3. להעלות הכול ל-GitHub → Settings → Pages → Branch: main / root.
4. כניסה ראשונה: `admin` / `ChangeMe123!` (המקלדת באנגלית) → החלפת סיסמה.

**נעילה אחרי 5 ניסיונות כושלים** — אפשר לחכות 15 דקות, או להריץ ב-SQL Editor:
```sql
update research.staff set failed_attempts = 0, locked_until = null where username = 'admin';
```

## אבטחה ופרטיות
- רק מספר סידורי — ללא שם/ת"ז/טלפון. טבלת הקישור נשמרת בנפרד, בבית החולים.
- הטבלאות בסכמה פרטית שאינה נגישה מהאינטרנט; כל פעולה עוברת דרך פונקציה שבודקת התחברות והרשאה בשרת.
- סיסמאות מוצפנות (bcrypt), נעילה אחרי 5 ניסיונות, ניתוק אחרי 20 דקות ללא פעילות, יומן פעולות מלא.
- הזנה שאושרה ננעלת לעריכה ולמחיקה (גם למי שיש הרשאה), עד ביטול האישור.
- לפני עבודה עם נתונים אמיתיים: אישור ועדת הלסינקי ואבטחת המידע לאחסון בענן חיצוני.
- גיבוי: ייצוא לאקסל פעם בשבוע (בגרסה החינמית של Supabase אין גיבויים להורדה).
